# Early Integration Program

The Early Integration Program helps teams integrate, experiment with and validate NZOChain security services in real product contexts.

Program page: https://nzochain.com/early-integration/

---

## What we offer

- Access to the public API resources available on your B2B plan
- Integration documentation in this repository
- Examples in multiple programming languages
- Technical accompaniment during integration, subject to team availability
- Collaboration to evaluate use cases
- Joint feedback and product improvement loops
- Possibility of evolving into a commercial relationship when both sides agree

Participation focuses on technical integration and validation. The program does not include financial support or grants, special free quotas beyond the published Free plan, SLA guarantees, free security audits, automatic partnership approval or guaranteed commercial deals.

---

## Who can participate

- Wallets
- dApps
- DeFi protocols
- Exchanges
- Web3 startups
- Developers
- Blockchain infrastructure teams
- Web3 security projects

---

## How to participate

1. Present your project.
2. Explain the use case and integration goal.
3. Contact the NZOChain team.
4. Technical alignment and evaluation.
5. Integration and validation against the public API and docs.
