# Assets

Public visual assets for the Early Integration Program repository may be placed in this folder.

## Rules

- Do not upload screenshots that contain API keys, tokens, emails, wallet addresses tied to real users, or private infrastructure URLs.
- Prefer diagrams and illustrations that explain public product concepts.
- Do not add proprietary source code, internal architecture diagrams marked confidential, or production configuration files.

## Status

No media assets are required for version `1.0.0` of this documentation set. Integration examples are text-based.
