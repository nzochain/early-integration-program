# Assets

Public visual assets for the Early Integration Program repository may be placed in this folder.

## Guidance

- Prefer diagrams and illustrations that explain public product concepts.
- Screenshots must not contain API keys, tokens, emails, wallet addresses tied to real users, or private infrastructure URLs.
- This folder is for public educational media only — not proprietary source code, confidential architecture diagrams or production configuration files.

## Status

No media assets are required for version `1.1.0` of this documentation set. Integration examples are text-based.
