# Contributing

Thank you for helping improve the public Early Integration Program documentation.

This repository accepts contributions that improve **documentation**, **examples** and **public educational resources**.

---

## Welcome contributions

- Suggest documentation improvements
- Report incorrect examples
- Propose new integration examples
- Fix typos, broken links or outdated parameter names
- Suggest use-case guides
- Contribute guides for additional languages (educational examples only)

Open an issue or pull request against https://github.com/nzochain/early-integration-program when the remote content is published.

---

## Rules

1. **No secrets.** Never include real API keys, tokens, passwords, `.env` values, private RPCs, customer logs or personal data.
2. **Placeholders only.** Use values such as `YOUR_NZOCHAIN_API_KEY` and `0xYOUR_WALLET_ADDRESS`.
3. **No proprietary code.** Do not submit NZOChain backend source, private configs or confidential architecture.
4. **No invented APIs.** Endpoints, fields and plan gates must match https://docs.nzochain.com/ or be clearly marked pending.
5. **No license grants.** Do not add an open-source license or claim reuse rights that have not been approved.
6. **Examples ≠ SDK.** Do not publish packages that imply an official `@nzochain/sdk`.

---

## Pull request checklist

- [ ] Placeholders only — no real credentials
- [ ] Links and endpoints verified against public docs
- [ ] Plan/feature gating wording is accurate
- [ ] English technical clarity; Portuguese summaries only where intentional
- [ ] No screenshots containing private data
